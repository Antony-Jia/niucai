# 第二阶段隔离联调交付与验收

日期：2026-10-08。先进行隔离环境联调，生产切换另行安排。

## 交付范围

本轮本地源码包含此前已验证的模型总时限、运行时停滞中断、租约撤销后取消执行，以及客户端断线状态同步、任务操作禁用和停滞提示。

新增任务结果区：按任务查询文件，显示摘要、已成功动作数、失败或待核对动作、最后成功观测的页面 URL，支持认证下载和 PNG/JPEG 截图预览。页面信息来自已有动作结果，不推断为当前实时页面。模型没有返回摘要时明确说明，不生成虚构摘要。

新增预览接口见 [API](api.md)。截图最多 2 MiB，超出或不支持时保留下载。没有数据库迁移。

只读浏览器画面标记超过 10 秒的旧画面、支持手动刷新；页面隐藏时停止刷新，重新显示时获取画面。切换到 Files/电脑配置会卸载预览。桌面连接区域提供重新连接和退出入口，顶部也可关闭连接；这些操作不代表控制权转移，交还以 Kernel 确认为准。

## Hermes 部署前需要确认

1. 将本交付的固定 Git 提交合入远端隔离测试分支，保留远端正在实施的改动。若冲突，按文件合并，不以 ZIP 覆盖远端工程。
2. 用同一提交构建 API 和 Worker；保留隔离项目自己的 `.env`、数据卷、Pi 会话和浏览器 profile，不替换生产配置。
3. 确认配置 `NIUCAI_MODEL_TIMEOUT=120`、`NIUCAI_RUNTIME_IDLE_TIMEOUT=300`（秒）。无进展监测只覆盖已领取任务，模型总时限也不代表外部副作用可撤销。
4. 返回隔离 API/桌面回环监听端口、API 与 Worker 提交/镜像 ID、Computer ID、测试时间和已完成项。凭据通过现有安全渠道配置，不写入记录或源码。
5. 确认隔离浏览器连接、导航、读取、截图可用；生产浏览器问题不阻塞文件任务联调。

## 本地连接隔离环境

以下远端 38080 / 36901 是上轮恢复栈端口示例，执行前替换成 Hermes 本轮确认的实际端口。新隧道与默认生产隧道使用不同本地端口、PID 和日志文件。

```powershell
.\start-remote-tunnel.ps1 -TunnelName integration `
  -LocalKernelPort 28080 -RemoteKernelPort 38080 `
  -LocalDesktopPort 26901 -RemoteDesktopPort 36901
```

客户端 Settings：Kernel 填 `http://127.0.0.1:28080`，Computer 填 `http://127.0.0.1:26901/vnc.html`，输入隔离栈的凭据。保存原生产连接信息，客户端目前一次连接一个 Kernel。

停止该隧道：`./stop-remote-tunnel.ps1 -TunnelName integration`。默认不传参仍使用原 18080 / 16901 及 remote 隧道。脚本继续校验 SSH 主机指纹，只绑定本地回环，无需新增公网端口。

## 联调矩阵

每项记录同一 task ID、关键 action ID、客户端/Kernel 提交、预期与实际结果、脱敏日志和截图。未执行的标待测，不能用单元测试替代。

| 顺序 | 操作 | 通过条件 |
| --- | --- | --- |
| 1 | Chat 转交文件任务，显式选择隔离电脑 | 只创建一个任务，定位正确任务和电脑，显示真实阶段 |
| 2 | 文件写入待审批，批准或拒绝 | 按钮出现在 Tasks 和工作台；审批只提交一次，拒绝不执行写入 |
| 3 | 运行中暂停、恢复、停止 | 操作以服务端允许项为准；停止后不开始后续动作，无永久假 RUNNING |
| 4 | 待审批时中断隔离隧道，再重建 | 显示待同步、禁用控制；恢复后审批/任务/电脑一致，不重复审批 |
| 5 | 关闭客户端再打开 | 保存的连接重新同步，任务及审批仍存在，不新建替代任务 |
| 6 | 用隔离可控模型制造超时/无进展 | 在配置上限及清理窗口内明确失败，保留原因；不自动重放不确定动作 |
| 7 | 打开隔离浏览器搜索任务，人工接管；模拟 VNC 登录/连接失败后退出并交还 | 交还请求仍到达 Kernel；失败不显示成功，控制权和可继续任务一致 |
| 8 | Agent 执行时观察画面；隐藏窗口再恢复 | 只读观察不抢控制权；隐藏时暂停请求，恢复后更新；旧画面有标记 |
| 9 | 查看完成/失败任务结果，预览截图、下载附件 | 文件只属于当前任务；预览与下载内容一致；失败保留已完成部分与待核对动作 |

固定浏览器目标：通过百度搜索金城武照片，读取结果并保存截图。遇登录、验证码或网络阻断应记录实际原因，不以静止画面推断 Agent 停止。
